# Tarefas para o projeto "O Porquê Eu Te Amo"

## Fase 1: Planejamento e estrutura do projeto Android
- [x] Criar o projeto Android base.
- [x] Definir a estrutura de pastas e arquivos.

## Fase 2: Criação da lista de 100 frases românticas
- [x] Gerar 100 frases de amor que completem "Eu te amo porque...".
- [x] Salvar as frases em um arquivo de recursos (strings.xml ou similar).

## Fase 3: Desenvolvimento da interface e layout
- [x] Criar o layout da tela inicial (minimalista, tons suaves).
- [x] Implementar a exibição da frase com tipografia elegante.
- [x] Adicionar elementos decorativos (corações, estrelas, flores).
- [x] Criar o botão de compartilhamento no canto inferior direito.

## Fase 4: Implementação da lógica do aplicativo
- [x] Carregar as frases do arquivo de recursos.
- [x] Implementar a lógica para exibir uma frase aleatória a cada abertura do app.
- [x] Implementar a funcionalidade de compartilhamento da frase atual.

## Fase 5: Criação de recursos visuais e ícones
- [x] Criar ícones para o aplicativo (launcher icon).
- [x] Criar ou encontrar imagens para os elementos decorativos (corações, estrelas, flores).

## Fase 6: Finalização e documentação do projeto
- [x] Testar o aplicativo em diferentes dispositivos/emuladores.
- [x] Otimizar o código e os recursos.
- [x] Escrever a documentação do projeto (como personalizar frases, etc.).
- [x] Preparar o aplicativo para entrega.
